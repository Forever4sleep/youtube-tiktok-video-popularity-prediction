## Тема проекта

Модель для предсказания популярности видео на TikTok или YouTube по метаданным и содержимому.

В качестве признаков планируется использовать:

- заголовок;
- хэштеги;
- длину ролика;
- время публикации;
- данные об авторе;
- жанр;
- текст;
- аудио;
- визуальные признаки.

Основная цель — предсказывать количество просмотров / лайков и исследовать, какие характеристики видео сильнее всего влияют на его популярность.

## Roadmap

### 1. Старт и планирование

- определить источник данных: TikTok / YouTube;
- определить целевую переменную и основные метрики;
- изучить доступные API и датасеты;

### 2. Разведочный анализ данных (EDA)

- собрать первый датасет;
- очистить и подготовить данные;
- изучить распределение просмотров и лайков;
- исследовать зависимости между признаками и популярностью видео;
- проанализировать заголовки, хэштеги, время публикации, длительность и данные об авторах;
- определить стратегию разбиения данных на train / validation / test;
- подготовить EDA notebook с основными выводами.

### 3. Первые ML-модели

- построить baseline;
- подготовить табличные признаки;
- добавить текстовые признаки;
- обучить первые модели:
  - Linear Regression / Logistic Regression;
  - Random Forest;
  - CatBoost / XGBoost;
- сравнить модели по выбранным метрикам;
- выбрать основную модель для дальнейшего улучшения.

### 4. ML-сервис

- сохранить обученную модель;
- реализовать inference pipeline;
- создать REST API на FastAPI;
- реализовать endpoint для получения прогноза;
- добавить простой интерфейс для демонстрации работы модели;
- подготовить рабочий end-to-end прототип.

## Промежуточная защита проекта

К промежуточной защите планируется иметь:

- собранный и исследованный датасет;
- результаты EDA;
- несколько baseline ML-моделей;
- сравнение их качества;
- работающий прототип ML-сервиса.

### 5. Улучшение ML-модели

- улучшить feature engineering;
- добавить более качественные текстовые embeddings;
- добавить признаки автора;
- провести подбор гиперпараметров;
- проверить новые гипотезы;
- провести анализ важности признаков;
- улучшить качество основной модели.

### 6. Нейронные сети

- использовать BERT-подобные модели для анализа текста;
- попробовать использовать транскрипты видео;
- исследовать визуальные признаки обложек и кадров;
- добавить аудиопризнаки;
- попробовать мультимодальную модель;
- сравнить нейросетевые подходы с классическими ML-моделями.

### 7. Финальные доработки

- выбрать финальную модель;
- провести итоговую оценку качества;
- доработать ML-сервис;
- добавить интерпретацию предсказаний;
- при возможности реализовать рекомендации автору по улучшению ролика;
- привести код и репозиторий в финальный вид;
- подготовить демонстрацию и итоговую презентацию проекта.
